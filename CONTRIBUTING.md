# Contributing

## Running the tests

```bash
pip install "ooxml-common @ git+https://github.com/uvrt/ooxml-common@main"   # or: pip install -e ../ooxml-common
pip install -e .[dev]
python -m pytest -q            # serial, as CI runs it
python -m pytest -n auto       # every core (pytest-xdist)
```

The **oracle tests are local-only**: they need Microsoft Word (driven by AppleScript on
macOS), its faces, or Word's exports outside the tree, and they skip wherever those are
absent -- including on every CI runner. Tests marked `faces` lay a document out in faces
only an Office machine has (Georgia, Cambria, ...) and skip where one is not installed.
`--run-slow` adds the raster fidelity scores.
More in [docs/development.md](docs/development.md).

## What never goes into the repository

- **No Microsoft font file**, in any form: not a file, a subset, a converted file or a
  blob embedded in a test artefact. Measurements taken from a face are facts and may be
  recorded as numbers.
- **No Office output**: no PDF Word exported, no raster or SVG made from one. They carry
  font subsets; the ground truth stays on the machine that measured it.
- **No third-party document** without a licence that allows redistribution, kept in its
  own directory with a `PROVENANCE.md` (source, date, licence, hashes). Fixtures should
  be generated by a committed `tools/make_*.py` script wherever possible.

## Pull requests

Open pull requests against `main`. CI runs the suite on Linux, macOS and Windows,
Python 3.10 to 3.15, and checks that the generated fixture is current
(`python tools/make_layout_sweep.py` leaves `tests/fixtures/` unchanged).

## Names docx-agent imports

`tests/test_public_api.py` imports every name docx-agent imports from here, and
[docs/api.md](docs/api.md), "Used by docx-agent", lists the same names, so renaming or
removing one fails this repository's CI instead of docx-agent's. To rename one, keep the
old name as an alias for one release, with a comment saying who it is kept for, and move
docx-agent over; a name docx-agent starts importing is added to both. docx-agent imports
no name that starts with an underscore: give it a public name first.
